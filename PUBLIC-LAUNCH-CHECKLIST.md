# Public Launch Checklist

This repository is structurally ready for a public launch.

## GitHub settings

When you are ready to publish:

1. Change repository visibility from **Private** to **Public**
2. Set the repository description to:
   **Production-first roadmap for LLM APIs, RAG, Evals, Agents, MCP, Security & Deployment**
3. Add the website/project URL later if you create a dedicated landing page
4. Add repository topics:
   - ai-engineering
   - generative-ai
   - llm
   - rag
   - agents
   - mcp
   - evals
   - ai-security
   - fastapi
   - ai-learning
5. Enable Issues
6. Enable Discussions if you want learners to ask questions publicly
7. Add a social preview image carrying:
   **Modern AI Engineering Path 2026 — by Mnawar Mohammed**

## First public milestone

Do not judge the launch only by stars.

Track:

- GitHub stars
- forks
- unique visitors
- clones
- inbound LinkedIn mentions
- people linking to the roadmap
- educators referencing it
- contributors opening issues/PRs

## Reputation strategy

The public repository should remain the canonical source. Build content around it:

- one LinkedIn post per module
- one long-form article explaining the full roadmap
- short technical breakdowns from individual lessons
- monthly project updates
- public release notes as the curriculum evolves

The objective is to make the phrase **Modern AI Engineering Path 2026** increasingly associated with **Mnawar Mohammed**.
