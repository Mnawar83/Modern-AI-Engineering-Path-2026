# Contributing

Thank you for helping improve **Modern AI Engineering Path 2026**.

This project is intended to evolve with the AI engineering field while staying practical, production-oriented and understandable.

## Useful contributions

Good contributions include:

- correcting technical errors
- updating deprecated APIs or packages
- improving exercises
- adding tests
- documenting production failure modes
- proposing eval cases
- improving security guidance
- adding implementation examples that reinforce an existing module
- identifying material that has become outdated

## What does not belong

Please avoid:

- adding tools only because they are fashionable
- turning the repository into a link dump
- large framework-specific rewrites without a clear learning benefit
- copied material that you do not have permission to contribute
- secrets, credentials or private datasets

## Contribution process

1. Open an issue describing the proposed change when it is substantial.
2. Keep pull requests focused.
3. Explain what problem the change solves.
4. Add or update tests when behavior changes.
5. Preserve the curriculum's production-first philosophy.
