## One-line description

A production-first roadmap for learning how modern AI systems are built, evaluated, secured and deployed.

## Short description

Modern AI Engineering Path 2026 is an independent curriculum created by Mnawar Mohammed that takes learners from model APIs and structured outputs through RAG, evals, agents, MCP, security, observability and production deployment.

## Positioning statement

The project is designed to close the gap between **using AI** and **engineering AI systems**.

LLM APIs · Structured Outputs · RAG · Evals · Agents · MCP · AI Security · FastAPI · Observability · Reliability · Docker · CI/CD
