# Module 01 — ML & Neural Foundations, Compressed

## Goal

Understand enough machine learning and neural-network theory to reason correctly about modern models without delaying practical AI engineering.

## Learn

- train/validation/test separation
- overfitting and leakage
- classification vs regression
- metrics and why the business problem chooses the metric
- gradient descent
- neural-network forward pass
- backpropagation intuition
- embeddings as learned vector representations
- transformers at a conceptual level: attention, context and next-token prediction

## Build

- one small scikit-learn classifier using a proper pipeline
- one two-layer neural network from scratch or with a framework
- one embedding similarity demo

## Optional deep track

If you want traditional ML engineering depth, expand this module into:

- feature engineering
- trees, random forests and boosting
- regularization
- clustering and PCA
- PyTorch training loops
- CNNs
- transfer learning

Those subjects matter, but they are not prerequisites for starting production LLM work.

## Done when

You can explain weights, gradients, embeddings, inference, overfitting and evaluation without treating a model API as magic.
