# Roadmap and competency map

The path is built around five competency layers.

## Layer 1 — Software engineering

You can write tested Python, use Git, call HTTP APIs, work with JSON, understand sync vs async code and keep secrets out of source control.

Modules: **00, 09, 11**

## Layer 2 — Model engineering

You understand tokens, context, sampling, structured outputs, embeddings and the practical boundary between prompting, retrieval and model adaptation.

Modules: **01, 02, 03, 04**

## Layer 3 — Quality engineering

You can build task-specific eval sets, track regressions, measure retrieval independently from generation and compare changes with evidence.

Module: **05**

## Layer 4 — Agentic systems

You can safely expose tools, design deterministic workflows, add agents only when dynamic planning is necessary, use human approval and connect reusable capabilities through MCP.

Modules: **06, 07, 08**

## Layer 5 — Production operations

You can deploy, observe and control the system under real constraints: latency, provider failures, budgets, rate limits, security boundaries and changing data.

Modules: **09, 10, 11**

## Graduation standard

You are ready for production AI work when you can explain not just **how** your system works, but:

- how you measure whether it works
- how it fails
- what it costs
- what data it can access
- what actions it can take
- how you stop unsafe actions
- how you debug one bad run
- how you roll back a bad change
