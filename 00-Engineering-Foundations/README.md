# Module 00 — Engineering Foundations

## Goal

Become comfortable with the software-engineering primitives that every later AI system depends on.

## Learn

- Python functions, classes, typing and exceptions
- virtual environments and dependency management
- Git: clone, branch, commit, merge, pull request
- HTTP methods, status codes, headers and timeouts
- JSON and JSON Schema
- environment variables and secrets
- synchronous vs asynchronous Python
- logging
- pytest
- basic SQL

## Labs

1. Call a public JSON API with `httpx` and handle timeout + non-200 responses.
2. Convert a nested API response into a typed Pydantic model.
3. Write an async function that executes five independent requests concurrently.
4. Build a tiny CLI and write tests for it.
5. Store and query records in SQLite.

## Done when

You can read an API reference and integrate the API without copying a tutorial line by line.
